## Track B — PARA app (~/Desktop/Home/PARA): native chat MVP (US-1)

5. **Baseline the lab feature**: commit the untracked `src/features/encryptedChat/` (4 files) as-is before building on it.
6. **Client extensions** (`client.native.ts` + `types.ts`):
   - `connectWithBridgeSession(scope, bridgeSession)` — restore-from-bridge-token path (seeds the SDK `Session` {userId, deviceId, accessToken, homeserverUrl} into the existing SavedDevice flow; stable per-install `deviceId` continuity is the checkpoint the smoke/E2EE test validates).
